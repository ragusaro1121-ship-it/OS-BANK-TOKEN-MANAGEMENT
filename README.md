# OS Bank Token Management System

## Project Description
OS Bank Token Management System is a database project used to manage customer tokens in a bank.

## Features
- Customer registration
- Token number management
- Service type management
- Token status tracking
- Waiting, Serving and Completed status

## Technologies Used
- MySQL
- SQL
- MySQL Workbench

## Database
Database Name: os_bank_token

## Main Table
customers

## Project Purpose
This system helps banks manage customer queues and token services efficiently.
